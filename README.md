# 🚗 AutoModels – Unreal Engine 5

AutoModels is an Unreal Engine 5 project showcasing high-quality automobile models with realistic materials, lighting, and environment setup.  
This project is focused on learning and demonstrating 3D asset integration, rendering, and scene composition in UE5.

---

## 📌 Features

- High-quality 3D automobile models  
- Realistic materials and textures  
- Lumen lighting enabled  
- Nanite-ready assets (if supported)  
- Clean and organized project structure  
- Optimized for real-time rendering

---

## 🛠️ Built With

- **Unreal Engine 5**
- **Quixel Megascans** (if used)
- **Blender / Maya** (for models, if applicable)
- **PBR Textures**
